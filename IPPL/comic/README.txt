# WebComics App - Desktop Layout & Reader

## Pages Included
1. `index.html` - Scalable Sign Up & Login page (with desktop card layout).
2. `home.html` - Discovery page featuring Search, Genres, Trending, and Latest Updates, with Dark & Light theme switcher.
3. `comic-details.html` - Comic details showcase for "The World After the Fall", with synopsis, stats, and episode list.
4. `reader.html` - Comic reader for "Episode 32", with comic panels and previous/next episode navigation.

## How to Run
Open `index.html` or `home.html` directly in your browser, or use VS Code's Live Server extension.

## Custom Images Guide
Drop your custom images directly into the `assets/` folder with these filenames:

### 1. Auth Page:
- `header-bg.png` : Header artwork for index.html

### 2. Trending Comics (home.html):
- `magic-emperor.jpg` : Cover for Magic Emperor
- `ranker-second.jpg` : Cover for Ranker Second
- `martial-reigns.jpg` : Cover for Martial Reigns
- `versatile-mage.jpg` : Cover for Versatile Mage

### 3. Latest Updates Comics (home.html):
- `reverse-world.jpg` : Cover for Reverse World
- `go-toubun.jpg` : Cover for Go-Toubun
- `shenwu-tianzun.jpg` : Cover for Shenwu Tianzun
- `evil-god.jpg` : Cover for Evil God

### 4. Comic Details Showcase (comic-details.html):
- `world-after-fall.jpg` : Cover for The World After the Fall

### 5. Reader Panels (reader.html):
- `comic-panel-1.jpg` : Episode page 1
- `comic-panel-2.jpg` : Episode page 2
- `comic-panel-3.jpg` : Episode page 3

*Note: All pages have built-in styled fallbacks, so the entire site displays and functions immediately even before you add images.*
