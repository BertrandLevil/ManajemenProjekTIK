4. GLOBAL DEFAULT PANELS (Fallback for all comics)
--------------------------------------------------------------------------------
If you don't want to create separate panels for every comic yet, you can also 
simply add these 3 shared files, and they will display for any comic that does 
not have comic-specific panels:
  • comic-panel-1.webp (or .jpg / .png)
  • comic-panel-2.webp (or .jpg / .png)
  • comic-panel-3.webp (or .jpg / .png)

*If no panel image exists at all, a sleek placeholder frame will automatically show.*
